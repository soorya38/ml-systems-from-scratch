## Machine learning:

Definition:
Machine learning is the process of enabling a computer to learn patterns from data, rather than explicitly programming the rules.

Process:
- Collect the dataset.
- Train the model using the dataset.
- The model learns(updating parameters) from the dataset.
- After training, the model can perform inference on new input(unseen).

Data → Dataset → Training → Trained Model → Inference → Prediction

Note:
- Training is computationally expensive because the model repeatedly updates the parameters.
- Inference is faster as the parameters are not updated. Only an output is predicted based on the provided input.

## Tensor:

Definition:
Tensor is a multi-dimensional container of numbers.

Examples:
Scalar -> 0D tensor
Vector -> 1D tensor
Matrix -> 2D tensor
Image -> 3D tensor
High dimensional tensors -> 4D ...tensors.

## Terms:

- data -> Information collected from real world.
- dataset -> Collection of data.
- Model -> A mathematical function which has learnable parameters that maps input to output.
- Training -> Updating the parameters using the dataset to make better predictions.
- Inference -> Using a trained model to make predictions on new inputs.
