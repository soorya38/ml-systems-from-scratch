## Supervised learning

Learning from examples with known correct answers.

## Linear regression:

Predicts a continuous number on a straight line relationship.

## Features:

The input variables used to make a prediction.

## Error:

Difference between the predicted answer and the actual answer.

## Loss function:

A single number that measures how bad a model's predictions are overall.

## Prediction:

The model's estimated output.

## Label/Target:

The correct output the model should predict.

## Mean squared error(MSE):

Average of the squared predictions errors. This is the standard loss for linear prediction.
